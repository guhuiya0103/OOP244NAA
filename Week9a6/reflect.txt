In this assignment, I learned how to manage dynamic memory and work with file input and output in C++. The Numbers class helped me understand why constructors, destructors, copy constructors, and assignment operators are important. One of the most challenging parts was creating a deep copy of the dynamic array. At first, I used the wrong value in the loop, so the numbers were not copied correctly. After fixing it, I understood that memory must be allocated before copying each value.

I also learned how operator overloading can make objects easier to use. The insertion and extraction operators allowed the Numbers object to work with different streams, such as cin, cout, ifstream, and ofstream. This assignment also showed me the importance of checking for self-assignment, releasing old memory, and keeping copied objects separate from original objects. Overall, this workshop improved my understanding of encapsulation, dynamic arrays, file handling, and safe memory management in C++.
