During this assignment, I learned more about dynamic memory and how it works together with pointers and different data types. The general concept of dynamic memory is not too hard to understand, but when it appears in code with pointer syntax, it becomes easier to get confused. One thing I learned from this assignment was the difference between int* data and int*& data. At first, they looked very similar to me, but after doing the assignment, I realized they behave differently. With int* data, the function only receives a copy of the pointer, so any change to the pointer itself will not affect the original one. With int*& data, the function can directly modify the original pointer because it is passed by reference. I found this concept confusing at first, especially when dynamic memory allocation was involved. Sometimes I knew the theory but still used the wrong one in my code. After debugging and tracing the variables step by step, I started to understand why references to pointers are useful and when they should be used.
