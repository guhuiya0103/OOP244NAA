This assignment helped me understand how important memory management is when working with dynamic data in C++. While implementing the LblShape class, I learned that every memory allocation using new[] must have a matching delete[]. I found a memory leak in the getSpecs() function because I created a temporary dynamic character array but did not release it. After fixing it, I realized that a regular local array was a better choice because it is automatically destroyed when the function ends. I also practiced inheritance by connecting LblShape to the abstract Shape class and overriding the getSpecs() function. Another challenge was keeping the function declarations and definitions exactly the same in both the header and source files. Overall, this assignment improved my debugging skills and helped me better understand dynamic memory, abstract classes, and polymorphism.
