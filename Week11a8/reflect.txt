This assignment helped me better understand inheritance and polymorphism in C++. Before starting, I knew the basic concepts, but I found it difficult to connect the base class and derived classes together. Implementing Shape, LblShape, and the derived classes helped me understand how pure virtual functions, override, and dynamic binding work in practice. I also got more experience working with dynamic memory by allocating and deleting the label correctly. One challenge I had was making sure the function declarations in the header matched the definitions in the source file, especially with std::istream, override, and inheritance. Debugging those errors taught me to pay closer attention to class relationships and function signatures. Overall, this assignment improved my confidence in using inheritance and writing cleaner object-oriented code.
