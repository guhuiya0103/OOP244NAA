This assignment strengthened my understanding of resource management in derived classes. By implementing the Transcript class, I practiced writing a constructor, copy constructor, copy assignment operator, and destructor while managing dynamically allocated memory correctly. It reinforced the importance of performing deep copies to ensure that each object owns its own resources and to prevent issues such as memory leaks or double deletion. I also gained a better understanding of how a derived class should cooperate with its base class by reusing the existing functionality of the Marks class instead of rewriting it. Throughout this assignment, I became more confident applying the Rule of Three in an inheritance hierarchy and managing ownership of dynamic resources. Overall, this project helped me better understand how inheritance and dynamic memory work together in object-oriented programming and prepared me for building more complex C++ applications.
