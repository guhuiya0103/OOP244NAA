This assignment helped me understand how function templates make C++ code more flexible and reusable. Instead of writing separate functions for different data types, I learned that a single template function can perform the same task for any type. While implementing the two dynaCopy templates and prnArray, I also reinforced my understanding of dynamic memory management, including allocating memory with new, releasing memory with delete[], and copying arrays safely. Since templates are compiled when they are instantiated, I also learned why their implementations need to be placed in a header file instead of a source file. Although this assignment was relatively short, it strengthened my understanding of generic programming, header-only modules, and writing reusable code that can be applied to different object types. Overall, it was a good introduction to templates and prepared me for using them in larger C++ projects.
